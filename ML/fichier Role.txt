FichierRôle

scripts/run_pipeline.pyPoint d'entrée unique — lance tout en 1 commande

src/ingestion/dataset_loader.pyCharge CWRU, NASA IMS, MAFAULDA + génère données synthétiques réalistes

src/cleaning/pipeline.py3 niveaux : L1 brut → L2 structuration → L3 features (FFT, Kurtosis, THD...)

src/training/trainer.pyIsolation Forest + Random Forest + LSTM avec Attention + Optuna tuning

src/inference/predictor.pyPrédiction temps réel — retourne HealthScore + RUL + Status + Explanation

src/simulator/esp32_simulator.pyRejoue les datasets comme l'ESP32 via WebSocket/MQTT

src/monitoring/drift_monitor.pyDétection drift PSI + KS → auto-retrain trigger

src/api/main.pyFastAPI REST + WebSocket pour Flutter

configs/config.yaml Tous les paramètres centralisés


Demarrer

pip install -r requirements.txt

# Entraîner (génère données synthétiques + nettoie + entraîne)
python scripts/run_pipeline.py --mode train --motors 15

# Simuler l'ESP32 en temps réel
python scripts/run_pipeline.py --mode simulate --speedup 50

# Lancer l'API pour Flutter
python scripts/run_pipeline.py --mode api
